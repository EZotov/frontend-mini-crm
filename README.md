# Frontend Mini-CRM

Базовый каркас и архитектурный фундамент для мини-CRM системы. На текущем этапе в проекте реализована полная инфраструктура для авторизации, работы с данными и защищёнными маршрутами, а также подготовлен набор UI-компонентов. 
Визуальная часть страниц находится в процессе разработки (за исключением страницы логина), но всё готово к быстрому масштабированию и наполнению контентом.

## 🚀 Текущий статус и реализованный функционал

Проект содержит готовую бизнес-логику и архитектурные слои, разбитые по ключевым модулям:

*   **🔐 Авторизация и безопасность:**
    *   Полноценный модуль аутентификации (вход в систему).
    *   Адаптированный роутер с поддержкой **Protected Routes** (защищённых маршрутов).
    *   Автоматическая проверка валидности токенов и умные редиректы (неавторизованных пользователей — на логин, авторизованных — на внутренние панели).
*   **📡 Интеграция с API:**
    *   Класс-обёртка `Api` над модулем **Axios** для централизованной обработки запросов.
    *   Стор-менеджер для управления глобальным состоянием (Auth, App, User).
    *   Вспомогательные хелперы для обработки сетевых ответов, ошибок и интерцепторов (interceptors).
*   **🧱 Компонентная база (UI-Kit):**
    *   Базовые атомарные компоненты для построения страниц.
    *   Готовое меню навигации (Sidebar / Navbar) для переключения между будущими разделами.
*   **📝 Работа с формами:**
    *   Контроллеры для управления состоянием форм.
    *   Базовые компоненты: универсальный контролируемый `Input` и обёртка `Form`.

---

## 🛠 Технологический стек

*   **Frontend-фреймворк:** React
*   **Стейт-менеджер:** Effector
*   **Маршрутизация:** React Router
*   **HTTP-клиент:** Axios
