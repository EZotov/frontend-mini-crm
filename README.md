# Frontend Mini-CRM

Фронтенд-приложение для системы управления взаимоотношениями с клиентами (Mini-CRM).

## 🚀 Текущий статус и реализованный функционал

Проект содержит готовую бизнес-логику, архитектурные слои и основные рабочие разделы, разбитые по ключевым модулям:

* **🔐 Авторизация и безопасность:**
  * Полноценный модуль аутентификации (вход в систему).
  * Адаптированный роутер с поддержкой **Protected Routes** (защищённых маршрутов).
  * Автоматическая проверка валидности токенов и умные редиректы (неавторизованных пользователей — на страницу входа, авторизованных — во внутренние разделы).
* **📡 Интеграция с API:**
  * Класс-обёртка `Api` над модулем **Axios** для централизованной обработки запросов.
  * Стор-менеджер на базе Effector для управления глобальным состоянием (`Auth`, `App`, `User`).
  * Вспомогательные хелперы для обработки сетевых ответов, ошибок и интерцепторов (interceptors).
* **🧱 Компонентная база (UI-Kit) и Layout-шаблоны:**
  * Базовые атомарные компоненты для построения интерфейса.
  * Готовые **Layout-компоненты** — шаблонные обёртки страниц с преднастроенными кнопками и базовыми действиями.
  * Система всплывающих уведомлений (**Toasts**) для информирования пользователя об успешных действиях и ошибках.
  * Навигационное меню (Sidebar / Navbar) для переключения между разделами.
* **📝 Работа с формами:**
  * Контроллеры для управления состоянием и валидацией форм.
  * Базовые компоненты: универсальный контролируемый `Input` и обёртка `Form`.
* **🗂 Реализованные разделы системы:**
  * **Компании** — управление базой компаний.
  * **Заказчики** — ведение списка клиентов и контактных лиц.
  * **Настройки** — управление личным профилем пользователя и раздел со списком всех пользователей (доступен для роли администратора).

## 📋 В планах (Roadmap)

Следующие разделы находятся в очереди на разработку:
* **Сделки** — создание и ведение сделок.
* **Воронки и этапы воронок** — настройка воронок продаж и управление стадиями.
* **Задачи** — постановка и контроль выполнения задач по клиентам и сделкам.
* **WS-соединение** — получение уведомлений о задачах и сделках по подпискам.

## 🛠 Технологический стек

* **Frontend-фреймворк:** React
* **Стейт-менеджер:** Effector
* **Маршрутизация:** React Router
* **HTTP-клиент:** Axios
* **Формы и валидация:** React-Hook-Form, Zod
