# Frontend Mini-CRM

Самих страниц с контентом сейчас нет, кроме страницы логина.

Но подготовлены:
    - Интеграция с API (Api класс обёртка над axios, стор менеджер и хелперы к нему)
    - Авторизация
    - базовые компоненты для построения страниц
    - контроллеры для форм (пока базовый инпут и форма)
    - меню навигации
    - адапитрован роутер под protected роуты (проверки токена и редиректы)
